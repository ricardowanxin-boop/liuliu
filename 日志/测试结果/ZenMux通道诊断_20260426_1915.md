## 判断

浏览器能打开 ZenMux 后台，只能证明 Web 控制台可访问；不能证明 Vertex 兼容 API 的某个模型编辑路由可用。

这次直连测试已经证明：

1. ZenMux 服务并非整体不可用。
2. 账号余额和 API Key 并非整体错误。
3. `openai/gpt-image-2` 的文字生图能力可用。
4. `openai/gpt-image-2` 的图片编辑能力当前不可用或路由未开放。

## 建议

短期不要继续用 ZenMux `openai/gpt-image-2` 做图生图主链路，否则会持续出现 `Resource not found`。

下一步建议二选一：

1. 联系 ZenMux 确认 `openai/gpt-image-2` 是否支持 Vertex `edit_image`，以及需要使用哪个模型 ID 或 API mode。
2. 在项目里把图生图主链路切到已验证可编辑的通道；ZenMux 暂时只保留文字生图或备用模型测试。

在没有确认 ZenMux 图片编辑路由前，不建议继续消耗真实调用反复测试同一路径。
