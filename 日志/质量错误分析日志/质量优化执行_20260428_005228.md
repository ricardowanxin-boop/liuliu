# 质量优化执行 2026-04-28 00:52:28

## 当前核心问题

1. 商品主体仍是最大风险：整体图生图会同步重绘商品、手部和背景，导致链条、吊坠、珠子、金属边缘、透明托盘结构发生漂移。
2. 真实感不稳定：模型会把真实照片的桌面纹理、皮肤纹理、布料纤维和轻微噪点当成脏点抹掉，出现“干净但假”的 AI 平滑感。
3. 手部/美甲方向是 P0 风险：手心朝上时，贴钻必须在手背侧甲面；如果结果图出现掌心侧、指腹侧或指甲内侧贴钻，必须标记为致命错误。
4. 自动质检不能替用户硬挡结果：真实接口已经付费调用时，应展示结果图，同时在图旁边给出分数、原因和复核提示，让用户决定是否使用。
5. 质检也不能过度误伤：MediaPipe 如果只是原图检测不稳定，应标记为复核风险，而不是直接判定结果图 P0。

## 本轮修改

- 后端质检硬失败规则调整：
  - 只有结果图手部缺失、关键点结构明显变化、掌心侧新增贴钻、指甲内侧贴钻、商品结构/颜色/关键细节漂移才触发硬失败。
  - 原图手部 MediaPipe 检测不稳定降级为 P2 复核风险，不再直接 P0。
- 后端重试策略调整：
  - P0 硬失败不再自动重试，避免继续烧真实接口并越修越坏。
  - 非硬失败才允许自动重试。
- 前端结果画廊调整：
  - 真实接口有返回图时，无论是否质检通过，都进入结果画廊。
  - 每组图展示原图 + 结果图 + 质检分 + 风险原因。
  - 顶部“导出全部”改为导出全部结果图；带复核风险的文件名前缀 `需复核_`。
  - 单张结果支持下载、预览和删除。
  - 底部生成按钮区域增加独立层级和阴影，避免滚动内容穿过按钮区域。
- 错题库脚本调整：
  - `原图手部未能被 MediaPipe 稳定识别` 归为 P2 复核风险。
  - 商品结构漂移、商品主体细节下降、掌心侧贴钻仍按 P0/P1 记录。
- 水印后处理调整：
  - 底部右侧轻色水印去除更保守，避免把局部背景误修成大块纯色。
