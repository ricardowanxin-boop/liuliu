## 🎯 最佳方案：ComfyUI + LoRA + 固定种子

### 为什么这个方案最适合你

**稳定性保证**：
1. **LoRA 训练** = 锁定风格基因
   - 训练后的 LoRA 就像"风格 DNA"
   - 每次生成都遵循这个 DNA
   - 不会出现风格漂移

2. **固定种子（Seed）** = 锁定随机性
   - 相同种子 + 相同提示词 = 100% 相同结果
   - 批量处理时可以设置种子范围（如 1-40）
   - 保证风格一致但细节有变化

3. **ComfyUI 工作流** = 可复现
   - 保存工作流 JSON 文件
   - 每次加载相同配置
   - 参数不会变

**4060Ti 16GB 性能评估**：
- SDXL 生成：1024x1024，约 15-25 秒/张
- LoRA 训练：50 张图，约 1-2 小时
- 批量生成 40 张：约 10-15 分钟
- ✅ **完全可以本地跑**

### 第三阶段：批量生成工作流（核心）

#### ComfyUI 工作流配置

**关键节点设置**：

1. **Load Checkpoint** 节点
   - 模型：SDXL 1.0

2. **Load LoRA** 节点
   - LoRA 文件：你训练的 LoRA
   - 强度：0.8-1.0（推荐 0.9）

3. **KSampler** 节点（关键）
   ```
   seed: 使用批量种子生成器
   steps: 25-35（推荐 30）
   cfg: 7-8
   sampler_name: DPM++ 2M Karras（推荐）
   scheduler: Karras
   denoise: 1.0
   ```

4. **Batch Seed Generator** 节点（自定义）
   ```python
   # 生成连续种子：1, 2, 3, ..., 40
   # 或者固定种子 + 小范围变化
   base_seed = 12345
   seeds = [base_seed + i for i in range(40)]
   ```

5. **Save Image** 节点
   ```
   filename_prefix: product_batch_
   格式：PNG（保留最高质量）
   ```

#### 批量生成策略

**方案 A：固定种子 + 微调提示词**
```
种子：12345（固定）
提示词变化：
- 图 1-10：ceramic mug, angle 1
- 图 11-20：ceramic mug, angle 2
- 图 21-30：ceramic mug, close-up
- 图 31-40：ceramic mug, with props
```
**优势**：风格 100% 一致，只有构图变化

**方案 B：种子范围 + 固定提示词**
```
种子：1-40（连续）
提示词：ceramic mug on wooden table, warm lighting, 2800K
```
**优势**：风格一致，细节有自然变化

**方案 C：混合方案（推荐）**
```
种子：固定基础种子 + 小范围偏移（±10）
提示词：核心固定 + 细节微调
```
**优势**：平衡一致性和多样性

## ⚠️ 常见问题和解决方案

### Q1：生成的图片风格不一致怎么办？

**原因**：
- LoRA 训练数据风格混杂
- LoRA 强度设置不当
- 提示词有随机性词汇

**解决**：
1. 重新筛选训练数据，确保风格统一
2. 提高 LoRA 强度到 0.9-1.0
3. 移除提示词中的 "various", "different", "random" 等词

### Q2：4060Ti 16GB 显存不够怎么办？

**症状**：
- 训练时报错 "CUDA out of memory"
- 生成时卡顿或崩溃

**解决**：
1. 降低批次大小到 1
2. 使用 `--lowvram` 启动参数
3. 关闭其他占用显存的程序
4. 使用 SDXL 而非 Flux（Flux 更吃显存）

**实测**：4060Ti 16GB 运行 SDXL + LoRA 训练完全没问题 ✅

### Q3：生成速度太慢怎么办？

**优化方法**：
1. 使用 DPM++ 2M Karras 采样器（最快）
2. 降低步数到 25（质量影响不大）
3. 使用 SDXL Turbo 模型（速度提升 4-8 倍）
4. 启用 xFormers 加速

**预期速度**：
- 优化前：25-30 秒/张
- 优化后：10-15 秒/张
- 40 张总时间：7-10 分钟

### Q4：如何保证 100% 一致性？

**策略**：
1. 使用固定种子（完全相同）
2. 提示词一字不差
3. LoRA 强度固定
4. 所有参数锁定

**注意**：100% 一致意味着生成的图片完全相同，通常不需要这么极端。建议使用"高度一致但有细节变化"的方案（种子范围 ±10）。
