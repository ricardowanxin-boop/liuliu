# 图像工坊 UI 架构与设计规范

版本：v1.0  
日期：2026-04-24  
适用范围：图像工坊 Web 工作台、AI 图片生成/编辑/批量出图系统、素材库与管理后台

## 1. 设计目标

图像工坊的 UI 目标不是做一个展示型官网，而是做一个能被电商运营长期使用的生产工具。界面需要同时满足“快速出图、批量管理、结果复用、成本可控、低学习成本”五个要求。

核心设计原则：

- 工作台优先：首屏直接进入生产界面，不做营销式首页。
- 中文优先：所有业务文案使用简体中文，模型名、文件名、API 名称可保留英文。
- 操作可追踪：每一次生成、编辑、批量任务都有状态、参数、结果和历史记录。
- 信息分区稳定：左侧导航、中间工作区、右侧结果区、底部队列保持一致，降低学习成本。
- 电商场景优先：预设、尺寸、提示词灵感、素材分类都围绕商品图、社媒图、广告图展开。

## 3. 页面清单

### 3.1 生成工作台

用途：根据提示词直接生成图片。

主要模块：

- 左侧导航：生成、编辑、批量、预设、历史记录、素材库。
- 顶部状态：API 密钥状态、额度消耗、帮助、通知、用户头像。
- 中间工作区：提示词输入、提示词灵感、参考图可选上传、模型参数、生成按钮。
- 右侧结果区：结果网格、视图切换、下载、更多操作。
- 底部队列：当前批次任务状态。

关键状态：

- 未输入提示词。
- 正在生成。
- 生成成功。
- 生成失败。
- 额度不足。

### 3.2 编辑工作台

用途：上传参考图后进行改背景、改风格、改材质、统一视觉等操作。

主要模块：

- 参考图上传区。
- 编辑需求输入区。
- 编辑类型快捷标签：换背景、统一风格、局部精修、商品场景化、文案本地化。
- 保留项设置：保留主体、保留构图、保留颜色、保留材质。
- 避免项设置：不要文字、不要水印、不要畸变、不要多余手指。
- 前后对比结果区。

关键状态：

- 无参考图时禁用生成按钮。
- 多参考图时显示来源角色，例如“商品图、风格图、背景图”。
- 结果支持“继续编辑”。

### 3.3 批量工作台

用途：一次性生成多张商品图、社媒图或广告图。

主要模块：

- 批量输入区：多行提示词、CSV/Excel 导入、商品字段映射。
- 批量参数：统一模型、尺寸、质量、输出格式、并发数。
- 批量队列：排队中、生成中、已完成、失败、已取消。
- 批量操作：全部开始、暂停队列、取消全部、失败重试、批量下载。
- 结果汇总：完成数、失败数、预估消耗、实际消耗。

关键状态：

- 队列为空。
- 部分生成完成。
- 任务失败可重试。
- 批量下载准备中。

### 3.4 素材库与历史记录

用途：管理上传素材、生成结果和历史任务。

主要模块：

- 筛选栏：项目、类型、风格、日期、尺寸、状态。
- 素材网格：缩略图、文件名、标签、来源任务。
- 图片详情抽屉：提示词、参数、参考图、生成时间、下载记录。
- 操作：收藏、复用提示词、继续编辑、移动项目、删除。

关键状态：

- 空素材库。
- 加载中。
- 多选模式。
- 图片详情打开。

### 3.5 设置与管理

用途：配置模型、API、额度、预设和团队权限。

主要模块：

- API 密钥：连接状态、最后检测时间、重新检测。
- 模型配置：默认模型、备用模型、默认尺寸、默认质量。
- 额度控制：日额度、项目额度、用户额度、批量任务上限。
- 预设管理：新增预设、编辑模板、排序、启用/停用。
- 团队权限：管理员、设计、运营、只读成员。

关键状态：

- API 未配置。
- API 已连接。
- 额度接近上限。
- 预设保存成功。

## 4. 全局布局规范

### 4.1 桌面端布局

推荐尺寸：1440px 到 1920px 宽屏工作台。

```text
┌─────────────────────────────────────────────────────────┐
│ 顶部状态栏：API、额度、帮助、通知、用户                   │
├──────────┬───────────────────────────────┬──────────────┤
│ 左侧导航 │ 中间工作区                    │ 右侧结果区   │
│ 240px    │ 自适应                        │ 420px-520px  │
├──────────┴───────────────────────────────┴──────────────┤
│ 底部批量队列                                             │
└─────────────────────────────────────────────────────────┘
```

推荐尺寸：

- 左侧导航：240px。
- 主工作区：自适应，最小 640px。
- 右侧结果区：420px 到 520px。
- 底部队列：180px 到 220px。
- 页面外边距：16px。
- 模块间距：16px。
- 卡片圆角：8px。

### 4.2 响应式布局

平板：

- 左侧导航收缩为图标栏。
- 右侧结果区移动到中间工作区下方。
- 批量队列变为横向滚动。

手机：

- 顶部显示项目名和关键操作。
- 模式切换变为顶部 Tab。
- 提示词、参数、结果分为三个页面或折叠区。
- 批量队列进入独立页面。

## 5. 导航规范

左侧导航分为四组：

- 项目操作：新建项目。
- 模式：生成、编辑、批量。
- 预设：产品摄影、生活方式、社交媒体、App 界面/样机、营销/广告。
- 工具：历史记录、素材库。

导航状态：

- 当前页面使用浅绿色背景和左侧绿色指示线。
- 悬停状态使用浅灰绿色背景。
- 禁用项降低透明度，不隐藏。

## 6. 视觉规范

### 6.1 色彩

主色：

- 品牌绿：`#2F7D46`
- 深墨色：`#1F2933`
- 背景白：`#FFFFFF`
- 页面底色：`#F7F8F6`

辅助色：

- 浅绿底：`#EAF4EC`
- 边框灰：`#E2E6E8`
- 弱文本：`#6B7280`
- 蓝色进度：`#3B82F6`
- 橙色排队：`#F59E0B`
- 红色危险：`#EF4444`

使用规则：

- 绿色只用于主操作、选中态、成功态和品牌识别。
- 蓝色只用于进行中状态和进度。
- 橙色只用于排队、等待、警告。
- 红色只用于取消、删除、失败。
- 页面整体保持浅色、干净、低噪音。

### 6.2 字体

中文推荐：

- 系统优先：苹方、Microsoft YaHei UI、思源黑体。
- Web 推荐：`Noto Sans SC` 或 `Source Han Sans SC`。

字号规范：

- 页面标题：24px / 32px。
- 模块标题：16px / 24px。
- 正文：14px / 22px。
- 辅助文本：12px / 18px。
- 按钮文字：14px / 20px。

### 6.3 图标

图标风格：

- 线性图标。
- 统一 1.5px 到 2px stroke。
- 默认 18px 到 20px。
- 关键操作可使用 22px。

图标使用：

- 生成：闪光/魔法棒。
- 编辑：铅笔/画笔。
- 批量：图层。
- 素材库：文件夹。
- 历史：时钟。
- 下载：向下箭头。
- 更多：三点。
- 帮助：问号。
- 通知：铃铛。

## 7. 组件规范

### 7.1 按钮

主按钮：

- 背景：品牌绿。
- 文字：白色。
- 高度：44px。
- 圆角：8px。
- 用于“生成、开始批量、保存预设”。

次按钮：

- 背景：白色。
- 边框：边框灰。
- 文字：深墨色。
- 用于“保存设置、查看 API 文档、下载”。

危险按钮：

- 文字或边框使用红色。
- 用于“取消全部、删除、移除密钥”。

### 7.2 输入框

提示词输入框：

- 高度：140px 到 180px。
- 支持字数统计。
- 右下角放置优化提示词图标。
- 聚焦态使用绿色边框或浅绿色阴影。

单行输入：

- 高度：40px。
- 圆角：8px。
- 标签在上，控件在下。

### 7.3 下拉选择

用于模型、尺寸、质量、输出格式。

规范：

- 高度：40px。
- 当前值左对齐。
- 右侧下拉箭头。
- 长选项截断但 tooltip 显示完整。

### 7.4 上传组件

参考图上传区：

- 虚线边框。
- 图标居中。
- 支持拖拽和点击上传。
- 显示格式和大小限制。

已上传图片：

- 显示缩略图。
- 右上角显示删除按钮。
- 多图时显示角色标签。

### 7.5 结果卡片

结果卡片包含：

- 图片缩略图。
- 左上角多选框。
- 底部下载按钮。
- 更多操作按钮。

更多操作包含：

- 查看详情。
- 复制提示词。
- 继续编辑。
- 加入素材库。
- 删除。

### 7.6 批量任务卡

任务卡包含：

- 缩略图。
- 文件名。
- 尺寸。
- 状态文本。
- 进度条。
- 更多操作。

状态颜色：

- 已完成：绿色。
- 生成中：蓝色。
- 排队中：橙色。
- 失败：红色。
- 已取消：灰色。

## 8. 交互规范

### 8.1 生成按钮

启用条件：

- 生成模式：提示词不为空。
- 编辑模式：提示词不为空且至少上传一张参考图。
- 批量模式：队列中至少有一条有效提示词。

点击后：

- 按钮进入 loading。
- 生成任务进入底部队列。
- 右侧结果区显示占位卡或进度状态。

### 8.2 任务进度

进度展示：

- 排队中：灰色进度条。
- 生成中：蓝色进度条。
- 已完成：绿色进度条。
- 失败：红色提示和重试按钮。

刷新方式：

- MVP 可用 2 秒轮询。
- 生产版建议使用 SSE 或 WebSocket。

### 8.3 图片下载

单张下载：

- 点击卡片底部“下载”按钮。

批量下载：

- 多选图片后点击“批量下载”。
- 后端打包 ZIP，前端显示“打包中”状态。

### 8.4 错误提示

错误类型：

- API 密钥未配置。
- 额度不足。
- 图片过大。
- 格式不支持。
- 生成失败。
- 网络超时。

展示方式：

- 可恢复错误使用页面内提示。
- 严重错误使用顶部 Toast。
- 表单错误就近展示。

## 9. 文案规范

按钮文案：

- 使用动词开头：生成、编辑、下载、保存、取消、重试。
- 不使用“确定一下”“搞一下”等口语。

状态文案：

- 排队中。
- 生成中 70%。
- 已完成。
- 失败，点击重试。
- API 密钥未配置。
- 额度不足，请联系管理员。

提示词灵感：

- 产品图。
- 柔和日光。
- 极简背景。
- 俯拍。
- 特写。
- 场景化。
- 高级质感。

## 10. 页面状态规范

空状态：

- 素材库为空：显示上传入口和示例说明。
- 历史为空：提示“完成一次生成后会出现在这里”。
- 结果为空：显示图片占位和“生成结果会出现在这里”。

加载状态：

- 使用骨架屏，不使用大面积转圈。
- 图片卡片先显示浅灰占位。

成功状态：

- 轻量 Toast。
- 任务卡状态变为绿色“已完成”。

失败状态：

- 卡片显示失败原因。
- 提供“重试”和“查看详情”。

## 11. 权限规范

管理员：

- 管理 API Key。
- 管理模型配置。
- 查看全部用量。
- 管理团队成员。

设计：

- 创建和编辑预设。
- 管理素材库。
- 生成和编辑图片。

运营：

- 使用预设。
- 上传参考图。
- 生成、编辑、批量下载。

只读：

- 查看项目。
- 下载已生成图片。
- 不可生成新任务。

## 12. 完整 UI 图建议清单

为了完整表达产品，不建议只出一张图。建议至少生成以下 5 张：

- 生成工作台：展示提示词、参考图、参数、结果画廊和底部队列。
- 编辑工作台：展示参考图上传、编辑需求、保留项/避免项、前后对比。
- 批量工作台：展示多行提示词、CSV 导入、队列进度、批量操作。
- 素材库/历史记录：展示筛选、素材网格、图片详情、复用提示词。
- 设置/API 与预设管理：展示 API 状态、模型配置、额度、预设模板和权限。

如果后续需要移动端，还应补充：

- 手机端生成页。
- 手机端结果页。
- 手机端批量队列页。

## 13. 交付标准

UI 设计稿验收：

- 至少覆盖 5 个核心页面。
- 所有业务文案为简体中文。
- 保持统一绿色品牌风格。
- 页面结构与产品技术方案一致。
- 生成、编辑、批量、素材库、设置均有明确入口。
- 不出现无意义英文占位文案。
- 不使用营销式大首页替代工作台。

前端实现验收：

- 页面响应式不重叠。
- 所有按钮有 hover、active、disabled 状态。
- 表单有校验和错误提示。
- 结果卡片、任务卡、素材卡可以复用同一组件体系。
- API Key 不出现在前端源码。
- 批量任务状态可实时刷新。

## 14. 总结

图像工坊的 UI 核心是“稳定生产工具”，不是“单次生图页面”。整体架构应围绕项目、模式、提示词、参考图、结果、队列、素材、设置八个对象展开。设计上保持浅色、低噪音、高可读性；交互上强调任务状态、结果复用和成本可控；页面上至少需要 5 张完整稿才能说明真实产品形态。
