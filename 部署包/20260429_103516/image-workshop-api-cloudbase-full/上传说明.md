# 图像工坊后端云函数上传说明

上传包类型：腾讯云 CloudBase HTTP 云函数。

## 函数配置

- 函数名建议：`image-workshop-api`
- 运行方式：HTTP 云函数 / Web 函数
- 启动文件：`scf_bootstrap`
- 监听端口：自动读取 `PORT` 或 `SCF_HTTP_PORT`，默认 `9000`
- 运行环境：推荐 Python 3.11
- 内存建议：1024MB 起步
- 超时建议：300 秒

如果上传 `image-workshop-api-cloudbase-full-*.zip`，包内依赖是按 Linux x86_64 / Python 3.11 打的，请在腾讯云函数里选择 Python 3.11。

如果上传 `image-workshop-api-cloudbase-source-*.zip`，需要在云端按 `requirements.txt` 安装依赖，可用 Python 3.10 或 Python 3.11，仍优先建议 Python 3.11。

## 环境变量

按 `DEPLOY_ENV.example` 在腾讯云函数控制台配置。不要把真实 Key 写进前端。

## 验证

部署完成后访问：

```text
https://你的云函数域名/api/health
https://你的云函数域名/api/config
```

前端静态包构建时已默认指向：

```text
https://wanxin1994-3g0nf07m2ee74437-1300762205.ap-shanghai.app.tcloudbase.com/api/image-workshop
```

如果你的云函数访问地址变了，需要重新构建前端或在 Vercel 配置 `VITE_API_BASE_URL`。
